Тест 1: Проверка создания транзакции и её данных в БД

Цель тестирования: Убедиться, что транзакция со всеми полями корректно сохраняется в базе данных с автоматическим присвоением ID.

Предпосылки:
База данных транзакций пуста. Счетчик ID сброшен в 1.

Шаги тестирования:
Отправить POST-запрос на создание транзакции с типом "доход", суммой 5000.50 и описанием "зарплата".
Ожидаемый результат: Запрос выполнен успешно . В ответе приходит сообщение "добавлена транзакция #1".

Проверить состояние базы данных.
Ожидаемый результат: В базе данных появилась одна транзакция с ID = 1. У этой транзакции:

ID совпадает с присвоенным
Тип "доход"
Сумма 5000.50
Описание "зарплата"

Размер базы данных стал равен 1.

Цель тестирования: Убедиться, что можно получить конкретную транзакцию по её идентификатору и данные соответствуют сохраненным в БД.

Транзакция #2: траты 500, "кофе"

Транзакция #3: доход 2000, "фриланс"

Тип = "траты"

Ожидаемый результат: Данные в ответе полностью совпадают с данными транзакции с ID=2 в базе.

Ожидаемый результат: Запрос выполнен успешно. В ответе приходит сообщение "транзакция #1 обновлена".

Ожидаемый результат: В базе данных по-прежнему одна транзакция с ID=1, но её данные обновлены:

Сумма изменилась на 1500

Описание изменилось на "ресторан с друзьями"

Тип остался прежним

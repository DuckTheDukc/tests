Тест 1: Проверка создания объявления и связанной структуры для отзывов
Цель тестирования: Убедиться, что при создании объявления оно корректно сохраняется в базе данных объявлений.

Предпосылки:
База данных объявлений и база отзывов пусты.

Шаги тестирования:
Отправить POST-запрос на создание объявления с заголовком "Продам ноутбук", описанием "Игровой ноутбук, состояние отличное", ценой 50000 и именем продавца "Иван Петров".
Ожидаемый результат: Запрос выполнен успешно. В ответе приходит сообщение "добавлено объявление Продам ноутбук".

Проверить состояние базы объявлений.
Ожидаемый результат: В базе объявлений появилась запись с ключом "Продам ноутбук". У этого объявления:

Заголовок совпадает с отправленным

Цена равна 50000

Имя продавца "Иван Петров"

Проверить состояние базы отзывов.
Ожидаемый результат: В базе отзывов появилась запись с ключом "Продам ноутбук", представляющая собой пустой список.

Тест 2: Проверка создания объявления с некорректной ценой
Цель тестирования: Убедиться, что система валидации не позволяет создавать объявления с ценой меньше или равной нулю, и базы данных остаются пустыми.

Предпосылки:
Базы данных объявлений и отзывов пусты.

Шаги тестирования:
Отправить POST-запрос на создание объявления с ценой равной 0.
Ожидаемый результат: Запрос завершается с ошибкой 400. Тело ответа содержит детализацию ошибки "цена должна быть больше 0".

Отправить POST-запрос на создание объявления с отрицательной ценой.
Ожидаемый результат: Запрос завершается с ошибкой 400.

Проверить состояние баз данных.
Ожидаемый результат: Обе базы данных остались пустыми. Ни одно объявление не было создано.

Тест 3: Проверка создания отзывов для объявления
Цель тестирования: Убедиться, что отзывы корректно добавляются в список отзывов конкретного объявления, и несколько отзывов накапливаются в этом списке.

Предпосылки:
В базе объявлений существует объявление "Квартира". В базе отзывов для него создан пустой список.

Шаги тестирования:
Отправить POST-запрос на создание первого отзыва для объявления "Квартира" с именем пользователя "Алексей", 
рейтингом 5 и комментарием "Отличная квартира, все понравилось". Ожидаемый результат: Запрос выполнен успешно. В ответе приходит сообщение "отзыв добавлен".

Проверить состояние базы отзывов.
Ожидаемый результат: В базе отзывов для объявления "Квартира" появился один отзыв. У этого отзыва:

Имя пользователя "Алексей"

Рейтинг 5

Комментарий "Отличная квартира, все понравилось"

Отправить POST-запрос на создание второго отзыва для того же объявления от пользователя "Мария" с рейтингом 4.
Ожидаемый результат: Запрос выполнен успешно.

Проверить состояние базы отзывов.
Ожидаемый результат: В базе отзывов для объявления "Квартира" теперь два отзыва.

Тест 4: Проверка получения объявления вместе с отзывами и средним рейтингом
Цель тестирования: Убедиться, что при запросе объявления по заголовку возвращается не только само объявление,
но и все связанные с ним отзывы, а также корректно рассчитывается средний рейтинг.

Предпосылки:
В базе объявлений существует объявление "Курсы английского". В базе отзывов для него есть три отзыва с рейтингами 5, 4 и 3.

Шаги тестирования:
Отправить GET-запрос на получение объявления "Курсы английского".
Ожидаемый результат: Запрос выполнен успешно.

Проверить структуру и содержимое ответа.
Ожидаемый результат: В ответе:

Секция "ad" содержит данные объявления

Поле "reviews_count" равно 3

Поле "reviews" содержит список из трех отзывов

Поле "average_rating" равно 4.0

Проверить соответствие с базой данных.
Ожидаемый результат: В базе отзывов действительно три отзыва для этого объявления.

Тест 5: Проверка удаления конкретного отзыва
Цель тестирования: Убедиться, что можно удалить конкретный отзыв по индексу, не затрагивая другие отзывы,
 и что при попытке удалить несуществующий отзыв возвращается ошибка.

Предпосылки:
В базе объявлений существует объявление "Услуги репетитора". В базе отзывов для него есть три отзыва с комментариями "Отзыв 0", "Отзыв 1", "Отзыв 2".

Шаги тестирования:
Проверить начальное состояние.
Ожидаемый результат: В базе отзывов для данного объявления три отзыва.

Отправить DELETE-запрос на удаление отзыва с индексом 1 для объявления "Услуги репетитора".
Ожидаемый результат: Запрос выполнен успешно. В ответе приходит сообщение "отзыв удален".

Проверить состояние базы отзывов после удаления.
Ожидаемый результат: В базе отзывов осталось два отзыва: с комментариями "Отзыв 0" и "Отзыв 2". Отзыв с комментарием "Отзыв 1" удален.

Отправить DELETE-запрос на удаление несуществующего отзыва с индексом 5.
Ожидаемый результат: Запрос завершается с ошибкой 404.

Тест 6: Проверка удаления объявления вместе со всеми отзывами
Цель тестирования: Убедиться, что при удалении объявления из базы объявлений автоматически удаляются и все связанные с ним отзывы из базы отзывов.

Предпосылки:
В базе объявлений существует объявление "Машина". В базе отзывов для него есть три отзыва.

Шаги тестирования:
Проверить начальное состояние.
Ожидаемый результат: Объявление "Машина" присутствует в базе объявлений. В базе отзывов есть ключ "Машина" с тремя отзывами.

Отправить DELETE-запрос на удаление объявления "Машина".
Ожидаемый результат: Запрос выполнен успешно. В ответе приходит сообщение "объявление удалено".

Проверить состояние базы объявлений.
Ожидаемый результат: Объявление "Машина" отсутствует в базе объявлений.

Проверить состояние базы отзывов.
Ожидаемый результат: Ключ "Машина" полностью отсутствует в базе отзывов.

Отправить GET-запрос на получение удаленного объявления.
Ожидаемый результат: Запрос завершается с ошибкой 404.

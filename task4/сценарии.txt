Тест 1: Проверка создания поста и его данных в БД

Цель тестирования: Убедиться, что пост со всеми полями корректно сохраняется в базе данных.

Предпосылки:
База данных постов пуста.

Шаги тестирования:
Отправить POST-запрос на создание поста с именем "моя первая запись", текстом "сегодня отличный день" и комментариями ["класс!", "согласен"].
Ожидаемый результат: Запрос выполнен успешно. В ответе приходит сообщение "добавлен пост моя первая запись".

Проверить состояние базы данных.
Ожидаемый результат: В базе данных появляется запись с ключом "моя первая запись". Название совпадает с отправленным, текст совпадает с отправленным,
список комментариев содержит два элемента: "класс!" и "согласен", размер базы данных стал равен 1.

Тест 2: Проверка создания дубликата поста
Цель тестирования: Убедиться, что при попытке создать пост с уже существующим названием возвращается ошибка, и существующий пост не перезаписывается.

Предпосылки:
В базе данных есть пост "моя первая запись" с текстом "сегодня отличный день" и пустым списком комментариев.

Шаги тестирования:
Отправить POST-запрос на создание поста с таким же названием "моя первая запись", но с другим текстом "другой текст" и комментарием ["комментарий"].
Ожидаемый результат: Запрос завершается с ошибкой 400. Тело ответа содержит детализацию ошибки "пост с таким названием уже существует".

Проверить состояние базы данных.
Ожидаемый результат: Размер базы данных не изменился. Существующий пост "моя первая запись"
 сохранил свои исходные данные: текст "сегодня отличный день" и пустой список комментариев.

Тест 3: Проверка получения всех постов
Цель тестирования: Проверить, что эндпоинт получения списка постов возвращает все созданные посты с корректными данными.

Предпосылки:
База данных постов пуста.

Шаги тестирования:
Создать несколько постов через POST-запросы:
Пост 1: "пост 1", текст "текст 1", комментарий ["комм1"]
Пост 2: "пост 2", текст "текст 2", пустой список комментариев
Пост 3: "пост 3", текст "текст 3", комментарии ["комм2", "комм3"]
Ожидаемый результат: Все запросы успешны.

Отправить GET-запрос на получение всех постов.
Ожидаемый результат: Запрос выполнен успешно. Тело ответа содержит список из 3 постов.

Проверить состояние базы данных.
Ожидаемый результат: В базе данных находятся все три поста. У поста "пост 2" комментарии отсутствуют, что соответствует созданным данным.

Тест 4: Проверка обновления текста поста с сохранением комментариев
Цель тестирования: Убедиться, что при обновлении текста поста существующие комментарии не теряются.

Предпосылки:
В базе данных есть пост "интересный пост" с текстом "начальный текст" и комментариями ["комм1", "комм2"].

Шаги тестирования:
Отправить PUT-запрос на обновление поста "интересный пост", изменив текст на "обновленный текст", но оставив комментарии без изменений.
Ожидаемый результат: Запрос выполнен успешно.

Проверить состояние базы данных.
Ожидаемый результат: У поста "интересный пост" текст изменился на "обновленный текст". Комментарии остались прежними: ["комм1", "комм2"].

Тест 5: Проверка удаления поста с комментариями
Цель тестирования: Проверить, что пост с существующими комментариями корректно удаляется из базы данных.

Предпосылки:
В базе данных есть пост "пост для удаления" с текстом "какой-то текст" и тремя комментариями: ["комм1", "комм2", "комм3"].

Шаги тестирования:
Проверить начальное состояние базы данных.
Ожидаемый результат: Пост "пост для удаления" существует в базе и содержит 3 комментария.

Отправить DELETE-запрос на удаление поста "пост для удаления".
Ожидаемый результат: Запрос выполнен успешно. В ответе приходит сообщение "пост удален".

Проверить состояние базы данных после удаления.
Ожидаемый результат: Пост с именем "пост для удаления" отсутствует в базе данных. База данных полностью пуста.

Цель тестирования: Убедиться, что задачи добавляются в базу данных корректно.

Предпосылки:
База данных задач пуста.

Шаги тестирования:
Отправить POST-запрос на создание задачи с именем "купить молоко" и статусом false.
Ожидаемый результат: Запрос выполнен успешно. В базе данных появляется запись с именем "купить молоко", статусом false, и размер базы данных становится равен 1.

Тест 2: Проверка создания дубликата
Цель тестирования: Убедиться, что при попытке создать задачу с уже существующим именем возвращается ошибка, и состояние базы данных не изменяется.

Предпосылки:

Отправить POST-запрос на создание задачи с именем "купить молоко" и статусом true.
Ожидаемый результат: Запрос завершается с ошибкой. Размер базы данных не изменяется,
а статус существующей задачи "купить молоко" по-прежнему false.

Тест 3: Проверка получения всех задач
Цель тестирования: Проверить, что эндпоинт получения списка задач возвращает все созданные задачи и соответствует состоянию базы данных.

Предпосылки:
База данных задач пуста.

Шаги тестирования:

Ожидаемый результат: Все запросы успешны. В базе данных находятся 3 задачи.

Отправить GET-запрос на получение всех задач.
Ожидаемый результат: Запрос выполнен успешно. Тело ответа содержит список из 3 задач. Проверка базы данных подтверждает,
 что в ней находятся именно те задачи, которые были созданы.

Цель тестирования: Проверить, что при обновлении задачи старая запись удаляется, новая создается корректно, а общее количество задач не меняется.

Предпосылки:

Шаги тестирования:

Ожидаемый результат: Запрос выполнен успешно.

Проверить состояние базы данных.
Ожидаемый результат: Задача с именем "купить молоко" отсутствует в базе. В базе присутствует задача с именем "купить хлеб" и статусом true.
 Размер базы данных не изменился и остался равен 1.
